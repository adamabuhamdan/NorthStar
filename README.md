## 📖 Overview

**North Star** is an intelligent browser extension that uses cutting-edge AI to help you stay focused on what truly matters while browsing social media. Powered by **Google Gemini AI**, the extension analyzes content in real-time, blurs distracting posts, and delivers smart summaries of the content that aligns with your goals.

Whether you're a student, professional, or anyone trying to be more intentional with their screen time — North Star is your compass in the noise.

## ✨ Key Features

### 🎯 Smart Content Filtering
Automatically blurs posts that don't match your defined interests and goals — putting *you* in control of what you see.

### 🤖 AI-Powered Summaries
Uses **Gemini AI** to intelligently summarize important content on Twitter and Facebook, saving you time without missing what matters.

### 📊 Distraction Analytics
Get detailed reports on your browsing patterns and understand the real productivity cost of distracting content.

### 📈 Live Statistics
Track in real-time how many posts have been saved vs. filtered — watch your focus score improve every session.

---

## 🚀 Installation

### Prerequisites

- Chrome or Edge browser (v88+)
- Node.js (for development)
- Python 3.8+ (for backend server)

### Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/your-username/north-star.git
cd north-star

# 2. Install dependencies
npm install

# 3. Start the backend server
pip install -r requirements.txt
python server.py

# 4. Load extension in Chrome
# Go to chrome://extensions → Enable Developer Mode → Load Unpacked → select /extension folder
```
